# Restore archival briefcase

Articulated retro metal archive case, built in Blender 5.2 for the office opening. Asset version 1.1.0, with a handle-free safe silhouette and engraved mechanical number wheels.

The editable source contains 298 separately modeled manufacturing parts. Its hollow base, shallow hollow lid, rolled rims, corner guards, interleaved hinge knuckles, slotted screws, sewn organizer pocket, twin clasp tongues and independent combination wheels are real geometry. Static surfaces are merged by material and moving parent for the runtime GLB.

## Files

- `restore-retro-briefcase.blend`: editable model and neutral studio, with final texture images packed into the file.
- `../../public/models/briefcase/briefcase.glb`: self-contained runtime export, including three atlas images and forty physical number glyphs.
- `textures/briefcase-basecolor-placeholder.png`: 2048 square placeholder material atlas generated by Blender Python.
- `textures/briefcase-basecolor-final.png`: enhanced 1254 square basecolor atlas, preserving the same four material quadrants without upscaling.
- `textures/briefcase-orm.png`, `textures/briefcase-normal.png`: original 2048 square physically based auxiliary maps. The runtime export uses 1024 square versions.
- `geometry-qa.json`: source manifold, UV containment, bounds and physical lid sweep checks.
- `roundtrip-qa.json`: independent Blender import of the actual GLB, checking geometry, transforms, embedded textures and the lid sweep.

The atlas uses painted olive metal in its upper left quadrant, warm aged hardware in the upper right, oxblood leather in the lower left and fine charcoal twill lining in the lower right. UVs use the same physical scale on both planar axes, with a .448 UV-per-metre scale and inset borders. Narrow walls, bevels and small fittings therefore retain fine material detail.

Each of four wheel drums has ten planar metal facets, evenly spaced at 36 degrees. Every facet has an actual Boolean-cut DIN numeral recess and a watertight black enamel inlay whose face sits 0.30 mm below the metal. One recessed separator line sits at each facet boundary. Smooth metal end collars replace the dense knurled teeth. Two fixed black reading arrows on the outer retainers identify the selected row. Every metal drum loop has its explicit flat facet normal, preventing interpolation artifacts around the engraving. There are no number textures, canvas displays or carry-handle attachments. The previous atlas is preserved; this revision changes modeled construction.

## Rebuild and verify

From the repository root:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/blender/briefcase-build.py -- --final
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/blender/briefcase-roundtrip.py
```

Add `--skip-renders` after `--final` for an export-only build. Omit `--final` to export the placeholder atlas. The script does not modify a running interactive Blender scene.

The .blend retains all separately modeled components. The exported GLB retains named articulation nodes: `Briefcase`, `LidPivot`, `LatchPivot_L`, `LatchPivot_R`, and `Wheel_0` through `Wheel_3`. Each wheel contains a metal mesh and `WheelNumerals_0` through `WheelNumerals_3` respectively. Every manufactured source component, including every number and separator inlay, is a closed manifold solid.

The runtime export is 51,808 triangles in 19 render meshes. The source QA rotates all forty glyphs into the front reading window, checks their height and inset, and ray-tests each glyph against its machined metal recess. Independent GLB reimport verifies twenty disconnected solid components per black wheel batch, meaning ten digits plus ten separators, and all forty upright centered detents.

The wheel pivots are `[(i - 1.5) * .132, .01, .358]`. Digit zero faces +Z with its top toward +Y. Digit k is authored at +X rotation `k * 2π / 10`, and the runtime reads it by rotating the wheel to `-k * 2π / 10`. Root metadata records this contract.

The coordinate contract is metres, Three.js X right, Y up, Z front. Body shell bounds are X ±.48, Y ±.10, Z ±.315. The lid pivot is `[0, .12, -.315]`; it opens by rotating X from zero to -1.75 radians. The closed lid shell spans local root Y .109 to .195. The GLB root has no compensating axis rotation.

These checks establish the modeled asset and exported hierarchy. They do not establish Quest frame rate, controller feel, or a mechanically simulated spring latch.
